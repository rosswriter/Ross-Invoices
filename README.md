# Ross Invoices (web)

My own invoicing software, as an installable web app for a tablet, a phone or a computer.

**Open it:** https://rosswriter.github.io/Ross-Invoices/

Then, in Chrome on Android: the ⋮ menu → **Install app** (or **Add to Home screen**). It opens like any app and
works with no connection.

- Everything you enter is kept **on that device, in that browser** — never in this repository, never on a server.
- Bring in your data from Ross Invoices on the laptop: there, *Settings → Export for Tablet*; here,
  *Settings → Import*. To go back: *Export Everything* here, *Import from Tablet* there.
- PDFs in both styles (Classic navy and INV circles), as on the laptop; on Android they save into a folder you
  choose (a folder for each year), or go straight into Gmail/WhatsApp with **Send…**.

Made with pdf-lib and fontkit (MIT) and the Inter typeface (SIL Open Font License); see `vendor/` and `fonts/`.
